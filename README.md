# Nombre del Proyecto

Descripción breve de qué hace el proyecto.

## Dependencias

Solo se requiere Node.js y Git LFS

## Instalación

### Repositorio

Para clonar el repositorio requiere instalar antes git lfs:

```bash
git lfs install
```

Para realizar pull en el repositorio se utiliza:

```bash
git lfs pull
```

### Backend

En el directorio Backend:

```bash
npm install
```

## Uso

En el directorio Backend:

```bash
npm run start
```

En el directorio Build

```bash
npx http-server -p <puerto>
```
